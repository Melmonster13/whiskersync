# Provenance

How this repository was built, and who did what.

## Tools

Built with [Claude Code](https://claude.com/claude-code) (Anthropic) as a pair programmer, using the ElevenLabs Python SDK against a live ElevenLabs account. Commits don't carry AI co-author trailers; this file records the collaboration instead.

## Workflow

Every change followed the same loop, set out in `CLAUDE.md`:

1. Claude proposed a plan: which files, the approach, open questions, and the options with a recommendation.
2. I approved, changed, or rejected it. Any change touching more than one file needed an explicit OK.
3. Claude implemented it and ran the offline test suite.
4. I approved the commit and push; CI had to pass on `main`.
5. Non-obvious choices were logged in [`DECISIONS.md`](DECISIONS.md) as they were made.

Live API calls, account settings, and GitHub repository settings were changed only with my explicit approval at the time.

## How correctness was established

- **Table-driven tests** for every module. The m2 suite generates every illegal `(state, event)` pair from the transition table.
- **Fault injection** between the agent's tools and the airline found two real bugs: non-JSON replies crashed the dispatcher, and a lost write was reported as a failure. Each was pinned as a strict expected-failure test first, then fixed.
- **A recorded live conversation** is the latency test fixture, trimmed to an allowlist of fields with ids replaced.
- **Live evals**: six scripted scenarios, checked by rules against the audit log and booking state, plus the ElevenLabs judge. All six pass.

## What went wrong, and what changed

- **Live evals ran by accident.** An unfiltered pytest run, with an API key in `.env`, started four live eval scenarios (920 credits). Live and eval tests are now excluded from every pytest run by default, and `make evals` checks the agent's voice model before spending anything.
- **Guesses that turned out wrong, or needed checking.** ElevenLabs rejected the v2.5 voice models for an English agent, so the agent uses Flash v2. The latency metric names weren't defined in the SDK and were guessed; all of them, including speech-to-text, were later confirmed against live conversations.
- **Echo in voice mode.** The first voice session picked up the agent's own voice through the laptop speakers. Voice sessions now print a reminder to use headphones.
